# 背景画像フォルダ

## 使い方

1. 使用したい画像を **`bg.jpg`** という名前でこのフォルダに入れる
2. アプリをリロードするだけで背景画像が適用される

## 対応フォーマット

| ファイル名 | 優先度 |
|---|---|
| `bg.jpg` | 第1位 |
| `bg.png` | 第2位 |
| `bg.webp` | 第3位 |

※ 複数あれば上から順に最初に見つかったものを使用。

## 推奨画像サイズ

- **最小**: 1920 × 1080px
- **推奨**: 2560 × 1440px 以上
- アスペクト比は問わず（`cover` で自動フィット）

## 画像がない場合

グラデーション背景（現行デザイン）に自動フォールバック。

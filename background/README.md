# 背景画像フォルダ

## 使い方

1. 使用したい画像を **`bg.jpg`** という名前でこのフォルダに入れる
2. アプリをリロードするだけで背景画像が適用される

## 手帖ごとの背景

| 手帖 | ファイル |
|---|---|
| 鉄の手帖 | `bg.jpg`（オリジナル） |
| 銅の手帖 | `bg_A2.jpg` |
| 銀の手帖 | `bg_B1.jpg` |
| 金の手帖 | `bg_B2.jpg` |
| 白金の手帖 | `bg_PT.jpg` |

手帖ごとのファイルが無い場合は `bg.jpg` を使う。

銅〜白金の背景は、オリジナルの `bg.jpg` から色合いを変えて自動生成している。
`bg.jpg` を差し替えたら `python3 tools/make_backgrounds.py` を実行すると4枚とも作り直される
（色合いはスクリプト内の GRADES で調整できる）。

## 対応フォーマット

| ファイル名 | 優先度 |
|---|---|
| `bg.jpg` | 第1位 |
| `bg.png` | 第2位 |
| `bg.webp` | 第3位 |

※ 複数あれば上から順に最初に見つかったものを使用。

## 推奨画像サイズ

- **最小**: 1920 × 1080px
- **推奨**: 2560 × 1440px 以上
- アスペクト比は問わず（`cover` で自動フィット）

## 画像がない場合

グラデーション背景（現行デザイン）に自動フォールバック。

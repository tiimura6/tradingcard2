# ハイレベル英単語図鑑 — ログイン・学習記録（GAS）セットアップ

所要時間：約10分。Googleアカウントがあればできます。

## 1. スプレッドシートとGASを用意する

1. Googleドライブで新しいスプレッドシートを作る（名前の例：`英単語図鑑_学習記録`）
2. メニュー「拡張機能 > Apps Script」を開く
3. 最初からある `コード.gs` の中身をすべて消し、このフォルダの **`Code.gs`** を貼り付けて保存
4. 左の歯車「プロジェクトの設定」で「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック → エディタに出てきた `appsscript.json` を、このフォルダの **`appsscript.json`** の内容で置き換えて保存

## 2. 初期セットアップを実行する

1. エディタ上部の関数選択で **`setup`** を選び「実行」
2. 初回は権限の確認が出るので「許可」（「このアプリは確認されていません」と出たら「詳細 > 安全ではないページに移動」）
3. スプレッドシートに戻ると、シートが自動で作られています

## 3. ウェブアプリとして公開する

1. Apps Script の右上「デプロイ > 新しいデプロイ」
2. 種類：**ウェブアプリ**
3. 次のユーザーとして実行：**自分**
4. アクセスできるユーザー：**全員**
5. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

## 4. アプリにURLを設定する

`index.html` の次の1行にURLを貼って保存し、GitHubに反映します。

```js
const GAS_URL = '';   // ← ここにURLを貼る
```

これで、アプリを開くとログイン画面が出るようになります。URLが空のままなら、ログイン機能は出ず、今まで通り端末保存だけで動きます。

> **Code.gs を修正したとき**は「デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン：新バージョン」で更新してください。「新しいデプロイ」を作るとURLが変わってしまいます。

## シートの見方

| シート | 内容 |
|---|---|
| **取り組み状況** | 生徒1人1行の一覧。先生が主に見るシート |
| 学習ログ | 1回答＝1行の生データ（会員・ゲスト両方）。最後の列が手帖 |
| 日別集計 | 生徒×日付ごとの回答数・正解数 |
| 殿堂入り | 殿堂入り達成者と達成日時。ランキングの元データ |
| ユーザー | 登録情報（パスワードは元に戻せない形で保存。先生にも見えません） |
| セッション・進捗データ | 内部用（非表示）。編集しないでください |

### 取り組み状況の列

| 列 | 意味 |
|---|---|
| 最終利用 / 未利用日数 | 最後に遊んだ日時と、そこからの日数。**3日以上で黄色、7日以上で赤** |
| 利用日数 | 1問以上解いた日の数 |
| 直近7日の回答数 | ここ1週間で解いた問題数 |
| 累計回答数 / 正解数 / 正答率 | 正答率60%未満は赤字 |
| 獲得カード / 収集率 | 全手帖 8,324枚中の取得数 |
| レベル / 累計XP / 連続ログイン | アプリ内の数値 |
| 撃破ボス数 | バトルで倒したボスの数 |
| 習得語数 | 忘却曲線（SRS）で「2週間後の復習」まで定着した単語数 |
| 殿堂入り / 殿堂入り日 | 達成者は🏆と黄色の背景（白金の手帖のボスラッシュ） |
| 開いている手帖 | 最後に保存したとき開いていた手帖（鉄・銅・銀・金・白金） |
| 鉄〜白金（枚） | 手帖ごとの所持カード数 |

見出し行のフィルタで、クラスで絞り込んだり、列で並べ替えたりできます。

## 先生用メニュー（スプレッドシート上部「英単語図鑑」）

- **選択中の生徒のパスワードをリセット**：「ユーザー」か「取り組み状況」シートで生徒の行を選んで実行し、仮のパスワード（英字と数字を含む8文字以上）を入力
- **選択中の生徒のデータをすべて削除**：卒業・転校・本人や保護者の申し出のときに。登録情報・進捗・学習ログ・集計・殿堂入りをまとめて削除（元に戻せません）
- **期限切れのログイン情報を削除**：たまに実行すると内部シートが軽くなります
- **今すぐバックアップ／毎週の自動バックアップを開始**：Googleドライブの「英単語図鑑_バックアップ」に全シートの値を写します（4回分を保存）。自動は毎週日曜の深夜
- **管理者キーを設定・変更**：アプリの「秘密の鍵」で全カードを解禁するキー。使えるのは「ユーザー」シートの「管理者（○で有効）」列に ○ を付けたアカウントだけ

## 効果検証レポート（学習ログの集計）
メニュー「英単語図鑑 → 効果検証レポートを作成」で「効果検証」シートが作られます（何度実行しても上書きされるだけ）。「毎朝自動で更新」を選ぶと毎朝5時ごろに更新されます。

- **要約**：応募書類・報告に使える文（克服率・正答率の変化・回答時間の変化・利用量との関係）
- **1. 間隔をあけた再挑戦**：同じ生徒が同じ単語（文法問題）に1日／7日以上あけて答えたときの正答率と、初回に間違えた単語の克服率
- **2. 利用量と伸び**：回答20件以上の生徒を利用日数で3等分して克服率を比較
- **3. バトルの苦手度ごとの正答率**
- **4. 週ごとの推移** ／ **5. 生徒ごと**（ログインIDのみ）
- 限界：アプリ内の回答（4択など）で、外部テストや対照群との比較ではありません。

※この機能を使うには Code.gs を貼り替えて「デプロイを管理 → 鉛筆 → 新バージョン」で更新してください（「新しいデプロイ」は選ばない）。

## クラス別集計

「取り組み状況」シートの「クラス（先生用）」列に、先生がクラスを書き込むと、「クラス別集計」シートに人数・直近7日の利用率・回答数・正答率などが自動で出ます。

## 仕様メモ

- 登録：ログインID（半角英小文字・数字・_ 3〜16文字）、ニックネーム、パスワード（英字と数字を含む8〜32文字）。氏名・クラスは集めない
- パスワードを5回続けて間違えるとロック（10分→1時間→24時間と長くなる）
- 「共用の端末」でログインすると、20分操作がなければ次に開いたとき自動でログアウト（記録は保存してから）
- 送信回数の制限あり（登録・ログイン・ログ・保存・管理者キー）
- 不自然な記録は「取り組み状況」の「要確認」列に記録（先生が消すまで残る）
- ログイン状態は180日有効。複数の端末で同時にログインできる
- 進捗は変更の8秒後と1分ごとに自動保存。アプリを閉じるときにも保存
- 別の端末で進んだ記録があると、起動時に自動で取り込む。両方の端末に未保存の変更があるときだけ、どちらを使うか生徒に選ばせる
- ログアウトすると、その端末の記録は消える（共用端末で次の生徒が新しく始められるように）。記録はアカウントに残る
- ゲストの回答も学習ログには残るが、取り組み状況とランキングには載らない
- 殿堂入りの判定はアプリ側で行い、その結果をサーバーに送っている。悪意のある改ざんまでは防げないので、怪しい記録は「殿堂入り」シートから行を削除すればランキングから消える

## 動作確認（開発者向け）

`tests/gas-e2e.js` は Code.gs をモックのスプレッドシートで動かし、アプリと通しで確認します（登録→学習→保存→取り組み状況・学習ログ→別端末で引き継ぎ→ログアウト）。

```
python3 -m http.server 8765 &
NODE_PATH=$(npm root -g) node tests/gas-e2e.js
```

# 時の回廊の手帖（世界史）引き渡しメモ

飯村さんへ。ブランチ `kyoyo-techo` の内容と、公開までにお願いしたいことをまとめました。

## 1. 追加したもの

- 新しい手帖「時の回廊の手帖（世界史）」（100枚、カードIDは `wh-1`〜`wh-100`）
  - 銀の手帖が開いている人に開く。すでに銀を持っている人には、起動時に1回だけ「新しい手帖が開きました」と知らせる
  - 鉄〜白金の本編とは別あつかい（全手帖コンプリート・殿堂入り・収集率には数えない）
  - 例文訳の教科書用語を強調、冒険の面に時代名（古代〜現代）
- 日本語の確認問題（4択10問。学習前と100枚収集後の2回、任意）
- GAS（`gas/Code.gs`）：取り組み状況に「時の回廊（枚）」列、学習ログに確認問題の段階・点数、効果検証レポートに確認問題の節
- 画像用エクセル（`WH_images_001-050.xlsx`・`WH_images_051-100.xlsx`）

## 2. GASの更新（必ずアプリより先に）

1. 新しい `gas/Code.gs` を Apps Script エディタの `コード.gs` にすべて貼り替えて保存
2. 関数 `setup` を1回実行
3. 「デプロイ > デプロイを管理 > 編集（鉛筆）> バージョン：新バージョン」→「デプロイ」（「新しいデプロイ」は選ばない。URLが変わってしまう）

先にアプリを公開すると、古いGASが時の回廊のカードを「存在しないカード」として要確認に書き込んでしまいます。新しいGAS＋古いアプリなら問題ありません。詳しくは `gas/README.md`。

## 3. main への反映

**GASの更新が終わってから** `kyoyo-techo` を main にマージしてください。

## 5. 公開後に守ること（カード番号を固定）

公開したら、**カードの No に入っている単語を別の単語に変えたり、行の順番を入れかえたりしない**でください。カードIDは `wh-<No>` で、生徒の所持カードや★（覚えた度合い）の記録はこのIDに付いています。番号がずれると、別の単語の記録になってしまいます。

例文・和訳・意味などの言い回しを直すのは大丈夫です（直したら `python3 tools/build_notebooks.py` で作り直し、`index.html` の `NB_DATA_VERSION` を上げる）。

# 自動テスト

アプリを実際にブラウザ（画面なしのChromium）で動かして、主な機能が壊れていないか確かめます。
修正のたびに実行してください（1回 約1分半）。

## 準備（最初の1回だけ）
```
npm install
npx playwright install chromium
```

## 実行
```
npm test                 # 全部
node tests/regression.js バトル   # 名前に「バトル」を含むテストだけ
```

## 確かめていること（14項目）
- 新規ユーザー／既存ユーザーの開始手帖
- 手帖の切り替え（再読み込みなし・背景・見出し・BGMが途切れない）
- BGMが重ならない（iPhoneと同じく消音が効かない環境で）
- カードを引く（50G・100G）、冒険でのXP・ゴールド、冒険の記録画面
- 4択に正解が2つ入らない、回答判定
- ★（忘却曲線の段階・覚醒クエスト）
- バトル（順番の編成・自動並べ替え・作戦・命中判定・撃退の演出）
- 管理者キー、殿堂入り（白金のみ表示・ボスラッシュの背景）
- 幅360pxの小さい画面で横にはみ出さない
